# Titanium — 网页侧边栏 AI 助手

[English](README.md) | **中文**

一个轻量的 Chrome / Edge 扩展：在任意网页打开右侧边栏与 AI 对话。发送消息时扩展读取当前页面的文字作为上下文，让 AI 结合页面回答。

- **自带模型接口**：连接任何 OpenAI 兼容接口（DeepSeek、本地部署的 Ollama / vLLM 等），API Key 只存在浏览器本地
- **按需读取页面**：只有发送消息时才读取，打开侧边栏不产生任何请求
- **混合感知**：默认注入页面文本 + 结构骨架，模型还可按需调用全文搜索、元素列表、页面高亮、表格完整提取、元素结构、视口截图（可选，需视觉模型）
- **页面操作**（默认关闭）：开启后 AI 可点击、输入、选择、按键、滚动、跳转网址、管理标签页
- **发送前脱敏**：手机号、身份证号、银行卡号默认打码后再发送（截图除外）
- **引用可溯源**：AI 引用的「页面原文」经校验命中才显示「来自当前页面」徽标
- **中英双语**：界面、提示词、工具文案与 AI 作答语言一并切换，首次按浏览器语言判定，之后可在设置里随时改
- **零依赖**：纯原生 HTML/CSS/JS，无构建、无第三方库、无外部 CDN，可离线安装使用

## 安装

1. 下载或克隆本仓库
2. 打开 `chrome://extensions` 或 `edge://extensions`，开启右上角**开发者模式**
3. 点击**加载已解压的扩展程序**，选择本仓库的 `extension/` 目录
4. 点击工具栏中的扩展图标打开侧边栏

> 请用**加载已解压**的方式安装 `extension/` 目录。不要用「打包扩展程序」生成 `.crx` 再拖进浏览器——Chrome 只接受由网上应用店签名的 CRX，自行打包的会以 `CRX_REQUIRED_PROOF_MISSING` 被拒绝。需要在组织内批量分发时，走企业策略强制安装（`ExtensionInstallForcelist` 指向自托管的 update manifest），或以「不公开」形式上架商店；策略安装的扩展不做这项签名校验。

### 浏览器版本要求

| 浏览器 | 要求 |
|---|---|
| Chrome / Chromium | **≥ 114。** `chrome.sidePanel` API 自 114 起提供；manifest 已声明 `minimum_chrome_version: 114`，低于此版本会直接拒绝安装。 |
| Microsoft Edge | **建议 ≥ 117。** Edge 从 115 起分批向稳定版推送侧边栏 API，114–116 上可能装得上却始终不显示面板。 |
| Firefox / Safari | 不支持。两者均无 Manifest V3 侧边栏 API，且火狐本就不在本方案覆盖范围内。 |

本扩展仅支持 Manifest V3，代码为 ES2020+ 且无构建、无转译，不提供任何低版本降级路径。可在 `chrome://version` 或 `edge://version` 查看当前版本。

## 配置

点击侧边栏右上角齿轮打开设置，填写接口地址、模型名称和 API Key，可点「测试连接」验证后保存。

| 配置项 | DeepSeek 官方 API | 本地部署（Ollama / vLLM 等） |
|---|---|---|
| 接口地址（baseUrl） | `https://api.deepseek.com/v1` | 如 `http://localhost:11434/v1` |
| 模型名称 | `deepseek-chat` | 部署的模型名，如 `qwen2.5:14b` |
| API Key | 在 [DeepSeek 开放平台](https://platform.deepseek.com) 申请 | 服务无鉴权可留空 |

> baseUrl 通常需要以 `/v1` 结尾（扩展会在其后拼接 `/chat/completions`）。测试连接返回 404 时请优先检查这一点。

设置抽屉里还有：语言切换（选中即生效）、发送前脱敏、模型支持视觉（启用截图工具，注意截图不经过脱敏）、允许页面操作。扩展不含任何数据统计或上报，页面内容只发送到你自己配置的接口，配置与 Key 仅存在 `chrome.storage.local`。

## 使用说明

- **读取时机**：发送第一条消息时才读取当前页面，状态条随即显示「已读取：{页面标题} · {N} 字 · {M} 个交互元素」；同一会话的后续消息不重复读取。点状态条可展开查看实际读取到的内容与页面结构。
- **重新读取**：页面内容变化后（如站内跳转），点状态条上的「重新读取」，下一条消息会携带新内容。
- **感知工具**：回答过程中模型自行按需调用，侧边栏实时显示活动行。问「XX 在页面哪里」时 AI 会在页面上画一个 3 秒的高亮框；长表格可以让它「完整提取第 N 个表格」，不受正文截断限制。要求接口支持 function calling（DeepSeek、主流网关均支持），不支持时自动降级为纯文本模式。
- **出处徽标**：AI 回复中的引用块若确为页面原文，右上角会显示「来自当前页面」徽标；没有徽标的引用请自行甄别。
- **快捷操作**：Enter 发送、Shift+Enter 换行；流式回复中可随时停止；悬停 AI 回复可复制全文或重新生成；「新对话」清空历史。
- **无法读取的页面**：浏览器内部页（`chrome://`）、扩展商店等无法读取，此时 AI 仅基于你的问题回答。

## 页面操作（默认关闭）

在设置抽屉的「允许页面操作」或输入区左侧「+」菜单中开启（两处同步），首次开启会有一次风险确认。开启后 AI 不再只是"看"，还能替你点击按钮、填写输入框、选择下拉项、按回车、滚动、跳转网址、开关标签页，适合「帮我把这个表单按上面的信息填好」「打开某某页面并总结」这类任务。

每个动作都在对话中以醒目的活动行实时呈现，流式过程中随时可点「停止」，未执行的动作会被跳过；转账、支付、下单、提交审批、删除等不可逆操作，AI 会先用文字说明后果并等你明确同意；页面跳转后元素编号自动重置，状态条提示下一条消息将重新读取。开关关闭时，操作类工具根本不会注册给模型。

**已知限制**：动作通过合成事件派发（`isTrusted` 为 false），极少数强校验站点可能忽略；自定义下拉组件需要 AI 先点开再点选项。请勿在处理不希望被改动的业务数据时开启。

## 与行内生产版的差异

鉴权/SSO 接入、域名白名单、网关侧二次脱敏与审计日志、按系统下发的适配规则、OCR 处理扫描件、操作类动作的审计留痕与二次授权——这些由行内已有能力承担，不在本版范围内。

## 常见问题

| 现象 | 排查 |
|---|---|
| 安装时提示 `CRX_REQUIRED_PROOF_MISSING` | 自行打包的 `.crx` 不被接受，Chrome 只认商店签名的包。改用「加载已解压」安装 `extension/` 目录，或通过企业策略分发 |
| 装上了但打不开侧边栏 | 浏览器版本低于要求，在 `chrome://version` 确认（Chrome ≥ 114、Edge ≥ 117） |
| 401 错误 | 检查 API Key 是否正确 |
| 404 错误 | 检查 baseUrl 是否以 `/v1` 结尾 |
| 网络失败 | 检查接口地址可达性；本地服务确认已启动 |
| 提示「接口不支持工具调用/图片输入，已降级」 | 接口或模型不具备该能力，属正常降级；换支持的模型即可恢复 |
| 提示「标签页已切换，请重新读取」 | 对话中途切换了标签页，点状态条「重新读取」后继续 |
| 点击/输入没反应 | 少数站点会忽略合成事件；也可能编号已过期，让 AI 重新列一次元素再试 |
