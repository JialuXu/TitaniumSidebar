# Titanium — 网页侧边栏 AI 助手

[English](README.md) | **中文**

一个 Chrome / Edge 扩展：在任意网页打开右侧边栏与 AI 对话。发送消息时扩展读取当前页面交给模型作为上下文——接口用你自己的 OpenAI 兼容接口（DeepSeek、本地部署的 Ollama / vLLM 等），Key 只留在浏览器里。

![页面操作：AI 在维基百科搜索、点击目录条目并引用该小节；每一步都以活动行呈现](docs/media/actions-en.gif)

- **自带模型接口**：任何 OpenAI 兼容接口都行；数据只发往你配置的接口，不含任何统计上报
- **只在发送时读页面**：打开侧边栏不读；每次发消息前自动跟进页面变化
- **看得到首屏之外**：模型可按需搜索页面、按位置读取正文、列出可交互元素、高亮定位、完整提取表格、截图（视觉模型）
- **页面操作，默认关闭**：开启后 AI 可点击、输入、选择、按键、滚动、跳转、管理标签页
- **发送前脱敏**：手机号、身份证号、银行卡号打码后再发（截图除外）
- **引用可溯源**：引用块与页面原文一字不差才显示「来自当前页面」徽标
- **中英双语、零依赖**：界面、提示词与作答语言一并切换；纯原生 HTML/CSS/JS，无构建、无 CDN，可离线运行

## 快速开始

**安装**：下载或克隆本仓库，打开 `chrome://extensions`（或 `edge://extensions`），开启**开发者模式**，点**加载已解压的扩展程序**选择 `extension/` 目录。点工具栏图标打开侧边栏。

> 请用**加载已解压**的方式。自行打包的 `.crx` 会以 `CRX_REQUIRED_PROOF_MISSING` 被拒——Chrome 只接受商店签名的包。组织内批量分发走企业策略（`ExtensionInstallForcelist`）或以「不公开」形式上架商店。

要求 **Chrome ≥ 114** 或 **Edge ≥ 117**（`chrome.sidePanel` API）。Firefox 与 Safari 没有 Manifest V3 侧边栏 API，不支持。

**配置**：点齿轮图标，在「模型接口」下填一套接口，可点「测试连接」验证，然后保存。

| 配置项 | DeepSeek 官方 API | 本地部署（Ollama / vLLM 等） |
|---|---|---|
| 接口地址（baseUrl） | `https://api.deepseek.com/v1` | 如 `http://localhost:11434/v1` |
| 模型名称 | `deepseek-chat` | 部署的模型名，如 `qwen2.5:14b` |
| API Key | 在 [DeepSeek 开放平台](https://platform.deepseek.com) 申请 | 服务无鉴权可留空 |

> baseUrl 通常以 `/v1` 结尾，扩展会在其后拼接 `/chat/completions`。测试连接返回 404 多半就是这一点。

- **多套接口**：「模型接口」右侧的「＋」再加一套，保存时下拉里选中的那套即为当前使用。「模型支持视觉」（启用截图工具；截图不经过脱敏）跟着每一套保存。
- **备份**：卸载扩展会连同设置一起清空。「导出设置」写出 `titanium-settings.json`，含全部接口与**明文 API Key**；「导入设置」整体恢复。「允许页面操作」不随文件走，需亲手打开。改代码后用扩展管理页的「重新加载」，设置不会丢。

## 日常使用

- **读取时机**：只在你发消息时读取。每次发送前扩展重新看一眼页面并自行判断：没变就什么都不重发；小幅变化（翻页、展开、AI 操作）只发几十行「变化摘要」；换了网址或大改才重发整页。没有「重新读取」按钮。顶部左侧的**页面胶囊**显示读到了什么，点开可看网址、字数、以及实际读取的正文与结构。
- **页面还在加载**：读取前先等内容稳定、加载指示器消失（最多约 2.5 秒）。等不到就照读，但会告诉模型「页面仍在加载」；模型自己也有「等待页面加载」工具，看到「暂无数据」占位会先等一等，而不是当成结论。
- **工具与长页面**：模型自行按需调用感知工具，每一步以浅色时间轴实时显示，回答出来后折叠成一行「已执行 N 步」。随消息发出的正文只有前 12000 字，再往后模型先搜索定位、再按位置读回那一段。问「XX 在页面哪里」它会在页面上画 3 秒高亮框；说「完整提取第 2 个表格」就能拿到整张表。接口不支持 function calling 时自动降级为纯文本。
- **出处徽标**：引用块与读到的页面原文一字不差才显示「来自当前页面」（按位置读回的原文同样算数）。没有徽标的引用请自行甄别。
- **历史会话**：每轮结束自动保存在本机（`chrome.storage.local`，最多 50 段或占满存储配额的八成，超出先淘汰最旧；某段存不进去时消息流里会提示）。左上角历史按钮可恢复、删除；恢复后直接接着聊。
- **`/compact`**：对话变长后，在输入框敲 `/compact`（可带指示：`/compact 只保留财报数字`）或用「+」菜单的「压缩上下文」，此前轮次收成一份摘要供后续请求使用，屏幕上的内容不变。压缩有损，且摘要请求与普通请求差不多大——**宜早压缩**：等普通请求已经超窗报错，压缩同样失败，只剩「新对话」。
- **边界**：浏览器内部页（`chrome://`）与扩展商店读不到，胶囊会标明，AI 仅基于你的问题回答。同源 iframe（含 `srcdoc` 与老系统的 frameset）并入页面一起读取与操作；跨域框架读不到，会告知模型有几个。
- **快捷操作**：Enter 发送、Shift+Enter 换行；随时可「停止」；悬停回复可复制或重新生成；「新对话」清空一切。

## 技能

技能是会话级的提示词包——纯指令、无代码——让 AI 进入特定任务模式。本版本内置三个：

- **表格提取（CSV）**：把页面表格完整转写为 ` ```csv ` 代码块，所有数字一字不差；可复制，也可下载为 Excel 直接打开的 `.csv`。
- **财报分析**：识别报表与报告期，每个比率写出公式，页面数字与推算数字严格区分。
- **行情解读**：只解释页面上的行情数据，不预测、不荐股，每次回答固定以免责声明结尾。

「+」菜单 →「绑定 Skill」启用；或在命中的财经站点上通过建议条一键启用（行情页建议「行情解读」，信息披露站点建议「财报分析」）。建议条只读取标签页网址。激活的技能显示为输入框上方可摘除的 chip，仅对当前会话生效。

## 页面操作（默认关闭）

在设置的「允许页面操作」或「+」菜单的「页面操作」开启（同一个开关；首次开启有风险确认）。之后 AI 可以点击、填输入框、选下拉项、按键、滚动、跳转网址、开关标签页——「按上面的信息把这个表单填好」「打开那个页面并总结」。

- 每个动作都以醒目的活动行呈现，点「停止」即跳过未执行的动作。
- 转账、支付、下单、提交审批、删除等不可逆操作，AI 先说明后果并等你明确同意。这是提示词层面的护栏，不是技术硬拦截。
- 每个动作之后扩展会等页面稳定（最多 5 秒）再看结果；仍在加载时会告诉模型「占位不可当结论」，模型可再等一等。
- 开关关闭时，操作类工具根本不会注册给模型。

**已知限制**：动作是合成事件（`isTrusted` 为 false），极少数强校验站点会忽略；自定义下拉组件需要 AI 先点开再点选项；加载判定只看页面本身、看不到网络请求，接口慢又不显示任何加载态的页面仍可能被读到空态（让 AI「再等几秒看看」即可）。请勿在不希望被改动的业务数据上开启。

## 与行内生产版的差异

鉴权/SSO 接入、域名白名单、网关侧二次脱敏与审计日志、按系统下发的适配规则、OCR 处理扫描件、操作类动作的审计留痕与二次授权，均由行内已有能力承担，不在本版范围内。

## 常见问题

| 现象 | 排查 |
|---|---|
| 安装时提示 `CRX_REQUIRED_PROOF_MISSING` | 改用「加载已解压」安装 `extension/` 目录，别用自行打包的 `.crx` |
| 装上了但打不开侧边栏 | 浏览器版本低于要求（Chrome ≥ 114、Edge ≥ 117），在 `chrome://version` 确认 |
| 重装后设置全没了 | 卸载会清空扩展存储；重装前导出、装好后导入；改代码用「重新加载」 |
| 401 | 检查 API Key |
| 404 | 检查 baseUrl 是否以 `/v1` 结尾 |
| 网络失败 | 接口不可达；本地服务确认已启动 |
| 提示「不支持工具调用/图片输入，已降级」 | 属正常降级；换支持该能力的模型 |
| 提示「标签页已切换」 | 对话中途切了标签页；切回原页，或直接就当前页面再问一句 |
| 点击/输入没反应 | 少数站点忽略合成事件，或编号已过期——让 AI 重新列一次元素 |
