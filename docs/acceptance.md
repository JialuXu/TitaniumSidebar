# 验收标准

改动功能后按对应条目验证；新增能力要补对应条目。条目编号只用于引用，不表示优先级。

其中 `core/` 能独立验证的部分已有自动化测试（见 [tests/README.md](../tests/README.md)），用例名里写了对应的「第 N 条」；界面、真实页面与真实接口上的表现仍按本清单手动验证。

1. 扩展加载无报错；在任意新闻/文档类真实网页上配置有效 API 后提问，能流式返回并正确渲染 Markdown（含表格与代码块）。
2. 打开侧边栏不产生任何页面读取与网络请求；发送首条消息后顶部出现页面胶囊（标题），点开浮层可见字数与交互元素数，请求体含已脱敏的 `<页面内容>` 与 `<页面结构>`。
3. 让模型"引用原文说明依据"，返回的引用块若确为页面原文则显示「来自当前页面」徽标；人为诱导模型编造引文时不显示徽标。
4. 含手机号/身份证样式文本的页面，脱敏徽标计数正确，且控制台打印的发送内容中已打码——包括工具结果里的搜索片段与表单值。
5. 页面没变时，第二条消息的请求体中不重复出现 `<页面内容>`；在页面上翻页/展开一段内容后再提问，请求体出现 `<页面更新>` 差异块且只有几十行；换个网址再提问，请求体出现新的 `<页面内容>` 全文，而**上一份全文已被压成一行占位**（历史里始终只有一份全文）。
6. 401/404/断网三种故障场景均有可读的中文提示。
7. 在支持 function calling 的接口（如 DeepSeek）上：问 12000 字截断之外的内容，模型**在 2 次工具调用之内**读到并据实作答（结构骨架里有该标题的 `@位置` 时直接 read_page_text；没有时先 find_in_page 拿 `@位置` 再读），**不应出现一连串关键词搜索**；问「XX 在页面哪里」，模型经 list_elements → highlight_element 在页面上画出高亮框（3 秒消失）；纯感知模式下连续诱导工具调用 5 轮后被强制直接作答，开启页面操作后为 15 轮。
8. 开启「模型支持视觉」并接入视觉模型：问页面布局，capture_screenshot 触发，活动行出现缩略图，图上编号框与元素对齐；回合结束后再次提问，请求体中旧截图已替换为占位文本。
9. 降级路径：接不支持 tools 的接口，一次 400 后自动去 tools 重试成功并出提示条；对话中途切换标签页再触发工具，得到「标签页已切换」的可读提示（下一条消息会自动读取当前页）；流式中点「停止」后继续对话不产生 400。
10. 页面操作开关**关闭**时，控制台打印的请求体里 tools 数组只含感知工具；诱导「帮我点搜索按钮」时模型答复自己没有操作能力并提示可去设置开启。
11. 开启后在 React 类站点（如 ant.design 表单 demo）说「在搜索框输入 X 并回车」：input_text 后页面的联想/校验确实响应（证明受控组件状态已同步），press_key 回车触发提交，活动行按 run → done 三态更新，无底色无边框，进行中 warn 色、完成后比感知行字色更深更粗。
12. 点开某个下拉菜单后问「有哪些选项」：工具结果中新出现的元素带 `*` 前缀。组件库的自定义下拉（antd Select / Cascader，ant.design 的 Select 与 Form 示例页）：list_elements 里下拉的输入框标为 `combobox`；AI 点外层带占位文字的那一项或内层输入框都能展开，新出现的选项带 `*`，点选项后控件显示该项，整个过程不出现「点了没展开」的排查轮次。
13. 说「打开 example.com 并总结」：navigate 活动行出现，页面胶囊换成新页标题；下一条消息的请求体携带新页 `<页面内容>` 并前置一句「用户当前浏览的页面已经变了」，消息流出现「页面已切换到…」提示行，而上一轮的工具结果里不含新页全文。
14. 在含「删除」按钮的页面说「把这条删掉」：模型先用文字说明将点击什么、后果是什么并等待确认，用户同意后才执行。
15. 动作执行过程中点「停止」：未执行的调用出现「（用户已中止，未执行）」占位，继续对话不产生 400；上一轮含动作时点「重新生成」会先弹二次确认。
16. 长表格页面（如维基百科条目）说「完整提取第 2 个表格」：extract_table 返回超出 12000 字截断范围的完整 Markdown，序号与结构骨架里的 #2 一致。
17. 设置里把语言切到 English：界面（含页面胶囊、「+」菜单、活动行、错误提示）立即变英文；控制台打印的请求体中 system prompt、tools 描述与 `<page_content>` 标签均为英文，AI 用英文作答；切回中文同理。重开侧边栏仍是上次选的语言。
18. 「+」菜单选中技能后：chip 出现、菜单项 hint 显示技能名；控制台请求体 system prompt 含技能正文（位于基础人设之后、只读/动作护栏段之前）且语言随界面语言；摘除 chip 或「新对话」后请求体不再含技能段。
19. 无激活技能时打开 quote.eastmoney.com：建议条出现「行情解读」；点「启用」→ chip 出现、建议条消失；点 ✕ 后同 host 本会话内不再建议；chrome:// 等受限页不出建议条；整个建议链路只读 tab.url，不产生任何脚本注入与网络请求。
20. 表格页启用「表格提取（CSV）」：模型经 extract_table 输出 ```csv 代码块、复制与下载按钮可用（下载得到 Excel 能正确识别中文的 .csv 文件）、抽查数字与原文一致；行情技能的回答末尾恒有「以上为页面信息整理，不构成投资建议。」；接口降级纯文本后（toolsBroken），请求体中技能正文仍在而 toolHint 段消失。
21. 有若干轮对话后输入 `/compact`（或「+」菜单「压缩上下文」）：不读页面、请求不带 tools、消息流出现「已压缩此前对话」且气泡仍在；下一条普通提问的请求体含摘要而不含压缩点之前的原文，并重新携带当前页 `<页面内容>` 全文；压缩失败后原上下文仍可继续对话。空会话或流式中该项不可用。切到 English 后摘要提示词为英文。恢复该历史会话后请求链仍走摘要、界面仍是原文。
22. 设置抽屉「模型接口」：「＋」新增第二套并填入另一接口，保存后下拉选中的那套生效——控制台请求打到该套的 baseUrl 且带其 Key；切回第一套保存后请求随之切换；只剩一套时「删除」置灰；改了字段不保存直接关抽屉再打开，改动不在；升级前的旧版配置（顶层 baseUrl/model/apiKey）启动后自动成为一套且可正常发消息；「模型支持视觉」随套保存，切换套后开关状态随之变化。
23. 「导出设置」得到 `titanium-settings.json`，内含全部接口与 API Key、不含 `actionsEnabled`；卸载重装扩展后「导入设置」选该文件，confirm 后接口列表、当前套、脱敏与语言全部恢复且立即可用，「允许页面操作」仍为关闭；选一个普通 JSON 或损坏文件，抽屉内出现「不是有效的 Titanium 设置文件」而配置不变。
24. 长页面（正文远超 12000 字）：请求体中 `<页面内容>` 之后有一行「该页正文共 N 字……」且 `<页面结构>` 中靠后的标题带 `@数字`；让模型「把第 X 章读完」，活动行显示「已读取「X」（正文第 a–b 字）」，续读的 offset 等于上一次返回的末位置、内容不重不漏；让它「通读全文」时单回合读取量达上限后给出可读提示而不是报错。跨读取边界的银行卡号/身份证号在控制台打印的发送内容里**仍是打码的**（切点不落在数字串中间）。引用截断之外的原文同样显示「来自当前页面」徽标。换个网址再提问，历史里旧的正文片段已被压成一行占位；恢复历史会话后重新生成，若页面已变，读取结果首行出现位置可能偏移的告警。
25. 内嵌框架：正文用同源 `<iframe srcdoc>` 嵌入的页面（论坛帖子、TinyMCE 编辑区），页面胶囊浮层的已读取文本里有框内正文，框内标题进结构骨架、框内表格的 #序号 与 extract_table 一致；框内的链接/按钮/输入框出现在 list_elements 里，高亮框画在元素上，截图编号框不偏位，开启页面操作后可点击、可输入（富文本编辑区的 input_text 生效）；带 `sandbox` 的 srcdoc 框架读得到文字但其内元素不编号；跨域框架读不到，页面统计里报「读取不到的跨域内嵌框架 N 个」；`display:none` 的框架不读也不计数；框架被移除或跳走后，按旧 ref 操作返回「元素已不存在」。
26. 等页面就位：判定只看文档是否解析完、元素级增删是否停下（静默约 0.6 秒），是不是「加载中」「暂无数据」这类占位由 AI 读页面内容判断。开启页面操作，在数据由接口异步加载的列表页（antd/element 表格，点「查询」后转圈 2–3 秒、表格区先显示「暂无数据」）说「查一下 X 并告诉我有几条结果」：AI 不会据「暂无数据」判定无结果、也不会 `go_back`，而是调用 `wait_for_page`（活动行「已等待 N 秒，页面已稳定」）后再读结果，回答的条数与页面一致。带常驻转圈或懒加载占位的页面（如 GitHub 的发布页、标签对话框）上，每个动作都在 1 秒左右返回；行情类持续增删元素的页面上，动作等满 5 秒后工具结果末尾出现「页面内容在 5 秒内持续变动」提醒；只有文字在跳的页面（时钟、行情数字）不算变动。刚打开一个页面就立即提问：胶囊「读取中…」持续到内容就位（不超过约 2.5 秒），若内容仍在变动则请求体的 `<页面内容>` 前有一句「读取时页面内容仍在变动」、消息流出现同义的小字；关闭页面操作后 `wait_for_page` 仍在 tools 里。自动化部分见 `tests/dom/settle.test.mjs`。
27. 过程时间轴：开启页面操作后让 AI 做一件需要多步的事（如「切到 X 标签并确认」）：活动行与中途说明段整体向右缩进，左侧浅色竖线把各步串起来、图标压在线上，进行中的那一步在末尾呼吸；最终回答出现后，过程折叠为一行「已执行 N 步，含 M 次页面操作」（有失败步时附「K 步失败」），点击可展开、再点折叠，含页面操作的摘要行比只读过程的字色更深；流式中点「停止」或请求报错且没有最终回答时，过程保持展开；从历史恢复该会话，过程默认折叠，展开后活动行、截图缩略图、说明段与当时一致；切到 English 后新回合的摘要行为英文（「Ran 3 steps, 1 page action」）。
28. 未注册的工具不执行：页面操作与「模型支持视觉」都关闭时，让网关（或本地假接口）在 SSE 里返回 `click_element` / `capture_screenshot`：页面没有任何变化、没有截图，活动行为红字「未执行 click_element：本次未开放此工具」，过程摘要不计入页面操作，tool 消息成对回填、继续对话不产生 400。纯感知模式下诱导到第 5 轮后，请求不再带 tools，此后返回的 tool_calls 一个也不执行（开启页面操作时为第 15 轮）。
29. 流结束时交出工具调用：假接口分别以「只发 `[DONE]` 不发 finish_reason」「最后一行 `data: [DONE]` 不带换行」「既无 `[DONE]` 也无 finish_reason、但参数是完整 JSON」三种方式结束带 tool_calls 的流：三种都照常执行工具，不出现空回复或「流中断」；参数截在半截（如 `{"ref":1`）就断流时报「流中断」，不执行。
30. 只有控件、没有正文的页面（纯登录表单、只有搜索框的页面）：发送后页面胶囊显示页面标题而不是「页面不可读」，请求体带 `<页面内容>`，里面是一句「此页没有可读的正文，只有按钮、输入框等可交互控件」，tools 含感知工具，问「这页有哪些输入框」时模型经 list_elements 作答；页面没变时第二条消息不再重复携带页面内容。
31. 动作后的标签页收养：开启页面操作，让 AI 点一个 `target=_blank` 链接，新标签页成为工作页，页面胶囊换成新页标题；让 AI 执行一串多步动作，在两步之间用户自己切到另一个已打开的标签页：工作页不跟过去，该步工具结果末尾出现「用户自己切到了另一个标签页」的提醒，同批后续动作得到「标签页已切换」而不执行，AI 在回复里问用户要回原页继续还是在新页面上继续；用户在新页面上发一条消息后，AI 就在新页面上工作。
32. 历史会话按大小淘汰：连续做几段带长页面、多次 read_page_text 的会话，DevTools → Application → Extension storage 里 `history.index` 每项带 `bytes`，全部会话记录合计不超过配额（`chrome.storage.local.QUOTA_BYTES`）的 80%，超出时最旧的会话从历史列表消失、其记录键同步删除；此时保存设置仍然成功。升级前的旧索引（无 `bytes`）在下一次保存后补齐。单段会话本身超出上限时，消息流出现一行红字「这段会话太长……」，其他历史会话一条不动、继续对话正常；其他原因写入失败时出现「未能保存到历史记录」，同一段会话只提示一次。切到 English 后两句提示为英文。
33. 结构骨架不丢后半截：标题远超 150 个的超长文档（如维基百科长条目、法规全文），`<页面结构>` 里仍能看到正文截断之外、带 `@位置` 的靠后标题（超预算时先省略 h4/h3，末尾注明省略了几个）；骨架节点超过 1000 个的页面，末尾多一行「结构过长，页面靠后还有 N 个节点未列出……」，模型据此改用 find_in_page 定位。
34. 上下文快满时提醒压缩：设置里给当前接口套填「上下文窗口」（如 `16k`；可写 `128000`、`128k`，保存后再打开显示为 `128k`，留空按 64k 估算，随套保存、随设置导出）；连续问几轮长回答，用量过约 70% 时消息流末尾出现警示黄提醒条「上下文已用约 N%（约 x / y tokens）……」并带「压缩」按钮，过 85% 换成红色的催促条（估算超过 100% 时措辞改为「已超出」），同一档只提醒一次、始终只留最新一条；「+」菜单「压缩上下文」的提示显示「/compact · 已用约 N%」。点提醒条上的「压缩」与 `/compact` 效果相同，回合进行中按钮置灰；压缩成功后提醒条消失、重新起算。接口在流里报 `usage.prompt_tokens` 时（如 DeepSeek），估算按真实用量校准，占比与接口计费的 token 数大致一致；请求体里**不**新增 `stream_options` 等字段。恢复一段很长的历史会话后立即出现提醒。请求真的超窗（400 且响应体含 context length 等字样）时：出现「请求超出了模型的上下文窗口……」而不是笼统的 HTTP 400，**不**出现「不支持工具调用，已降级」提示条、下一轮请求仍带 tools；此时再压缩也超窗则提示只能「新对话」。切到 English 后提醒条、按钮与错误提示均为英文。
35. 组件库勾选类控件与动作后的状态变化：开启页面操作，打开 Element UI 的 Checkbox 与 Table 多选示例页（element.eleme.cn）：list_elements 里每个勾选框都是 `checkbox`，名称是旁边的文字（表格行的带行锚点），截图编号框画在看得见的方框与文字上；让 AI「勾选第二行」，工具结果里有「当前已选中」，并在「已有元素的状态变了」下列出该勾选框 `未选中 → 「已选中」`，页面上的方框确实勾上；表头半选时该项显示「部分选中」，点成全选后结果如实报出。Element 的 Switch 只出现一个 `switch` 编号。让 AI 点一个点了没反应的勾选框时，结果里出现「点击后它的勾选状态没有变化」。antd 的 Select 选完选项后，状态变化里能看到下拉显示的文字换成所选项、展开态变为收起，AI 据此确认结果。每个回合结束后控制台打印一行「[回合统计]」，含轮数、调用数、各工具次数、失败原因与点击无效次数。第 12 条的 antd 下拉与第 25 条的框架内操作不回归。自动化部分见 `tests/dom/`。
36. 批量动作：开启页面操作，在一张有五六个字段的表单页（如 ant.design Form 示例）说「把姓名填 X、手机填 Y、城市选上海、勾选同意协议」：AI 用一次 batch_actions 完成这些步骤，活动行显示「已批量执行 N/N 步」，工具结果（控制台）逐步列出每一步，末尾一份合并后的页面变化（中途展开又收起的下拉、出现又消失的选项不出现在里面）。让某一步的编号指向折叠区域里的元素：执行停在那一步，结果写明第几步失败、其余几步未执行，活动行为红字「批量执行停在第 k 步」。批量里有一步会跳转页面时，后面几步不执行，结果写明原因。说「填完并提交」时，提交按钮单独执行且先征得用户同意。「[回合统计]」里 batch_actions 计一次调用。
37. 按键真的生效：开启页面操作，在一个带长文本框的表单页（文本框内容超出可见高度）说「把这个文本框翻到下面看看」：press_key PageDown 后文本框确实向下滚动，工具结果写「输入框滚动了 N 像素」；在文本框里按 Home / End / 方向键，结果写明光标从第几个字符移到第几个；焦点不在输入框时 PageDown / End / Home 滚动页面或所在的可滚动区域；Backspace / Delete 真的删掉字符，受控组件（React / Vue 表单）的值随之更新。已经在页面顶部再按 Home 时，结果写「按键后光标、滚动位置与内容都没有变化」，活动行为「已按下 Home（页面无变化）」。页面自己处理方向键的下拉（antd Select 展开后按方向键）照常切换选项，结果写「页面自己处理了这个按键」。说「读一下标准 9 的完整描述」时，AI 用 get_element_html 一次读到文本框的完整当前值（含刚改过的内容），list_elements 的 query 用文本框里的文字也能找到它。自动化部分见 `tests/dom/keys.test.mjs`。
38. 调试通道：设置抽屉「允许页面操作」下方有「调试通道（真实点击与按键）」开关，默认关闭；打开并保存时先弹确认（说明真实输入与「正在调试此浏览器」横幅），取消则保持关闭；导出的设置文件里没有这个开关，导入不改变它。从 manifest 去掉 `debugger` 权限后重新加载扩展，开关置灰、下方灰字为「当前版本没有调试权限」，页面操作照常走合成事件。开启后：AI 在一个回合里第一次操作页面时浏览器顶部出现调试横幅，回合结束后消失；Element UI 勾选框、antd 下拉、文本框的 PageDown / Home / 方向键都由浏览器按真人输入执行（DevTools 里监听到的事件 `isTrusted` 为 true）；点「查询」后工具结果里新增元素是接口返回后的结果行（接口拖慢到 8 秒以上时末尾出现「这次操作发出的 N 个网络请求还没有返回」）；卡片中心正好压着「删除」按钮时，点卡片不会点到删除，结果注明「这一步改用合成事件点击」；回合进行中点横幅上的「取消」，后续动作改用合成事件并注明。关闭开关后一切行为与第 11、12、26、37 条相同。自动化部分见 `tests/dom/cdp.test.mjs`。
